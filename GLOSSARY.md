# Learn skills

The words used by the `laravel-learn` and `tanstack-learn` skills to describe the lessons they write for the owner.

## Language

**Lesson**:
One ticket's worth of work the owner builds by hand, with a README and a Guide in `learn/NN-slug/`.

**Guide**:
The lesson's step-by-step document (`GUIDE.md`) the owner follows while typing the code.
_Avoid_: Tutorial, instructions

**Step**:
One chunk of a Guide that teaches at most one new idea through one command, file, or wiring change.

**Opener**:
The one plain line before a Step's code that says what this code _is_, often with an everyday picture.

**Walkthrough**:
The numbered explanation after a Step's code that quotes each piece of code and says what it does and why it is there.
_Avoid_: Markers, line notes

**Sub-label**:
The bold `Inside …:` line that groups the Walkthrough items for one block of code, such as a method body or a callback.
_Avoid_: Sub-heading, section

**In short**:
The one-or-two-sentence recap that closes a Step, right before its Run line.
_Avoid_: Summary, recap

**Picture**:
An everyday analogy that stands for one idea (like "the bouncer at the door" for a route guard) and is reused whenever that idea returns.
_Avoid_: Metaphor
